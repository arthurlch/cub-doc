# キーバインド一覧

以下はすべてデフォルトです。グローバルとビューモードのバインドは[設定ファイル](/ja/guide/configuration)
で完全に再割り当てできます。インサートモードの入力とビジュアルモードの操作子は固定です。

## グローバル（全モード共通）

| キー | 動作 |
| --- | --- |
| `Ctrl+S` | 保存 |
| `Ctrl+Q` | 終了 |
| `Ctrl+H` | ヘルプオーバーレイの切り替え |
| `Ctrl+P` | コマンドパレット（ファジーファインダー） |
| `Ctrl+T` | テーマ切り替え |
| `Ctrl+B` | ファイルサイドバー（表示 / フォーカス / 戻す） |
| `Ctrl+E` | サイドバーを反対側へ移動（左 / 右） |
| `Ctrl+←` / `Ctrl+→` | 前 / 次のタブ |
| `Ctrl+N` | 新しいタブ |
| `Ctrl+W` | タブを閉じる |
| `Ctrl+↑` / `Ctrl+↓` | 上 / 下にカーソルを追加 |
| `Ctrl+G` | 統合ターミナルの切り替え |

## ビューモード

| キー | 動作 |
| --- | --- |
| `i` / `a` | カーソルの前に挿入 / 後ろに追記 |
| `o` / `O` | 下 / 上に新しい行を開いて挿入 |
| `h` `j` `k` `l` または矢印 | 左 / 下 / 上 / 右へ移動 |
| `0` / `^` / `$` | 行頭 / 最初の非空白 / 行末 |
| `w` / `b` | 次 / 前の単語 |
| `gg` / `G` | ファイルの先頭 / 末尾（`<数字>G` で行ジャンプ） |
| `PgUp` / `PgDn` | 半画面スクロール |
| `x` | カーソル位置の文字を削除 |
| `dd` / `yy` | 現在行を削除 / ヤンク |
| `p` / `P` | 後ろに / 前に貼り付け |
| `u` / `Ctrl+R` | 取り消し / やり直し |

## ビジュアル（選択）

`v` で選択を開始し、移動して範囲を広げます。

| キー | 動作 |
| --- | --- |
| `v` | ビジュアル選択の開始 / 解除 |
| `y` | 選択範囲をヤンク（コピー） |
| `d` / `x` | 選択範囲を削除（カット） |
| `p` | 選択範囲に貼り付け |
| `Esc` | 選択を解除 |

## インサートモード

| キー | 動作 |
| --- | --- |
| `Esc` | ビューモードに戻る |
| 任意の文字 | 挿入する |
| `Enter` | 改行 |
| `Tab` | スペース 4 つを挿入 |
| `Backspace` / `Delete` | カーソルの前 / 位置を削除 |
| 矢印、`Home`/`End`、`PgUp`/`PgDn` | カーソル移動 |

## ターミナル（フォーカス中）

| キー | 動作 |
| --- | --- |
| `Ctrl+G` | パネルを非表示 |
| `Esc` | フォーカスをエディタに戻す |
| `Ctrl+N` / `Ctrl+W` | シェルの新規 / クローズ |
| `Ctrl+←` / `Ctrl+→` | シェルを切り替え |
| `Ctrl+↑` / `Ctrl+↓` | パネルを拡大 / 縮小 |

## サイドバー（フォーカス中）

| キー | 動作 |
| --- | --- |
| `Ctrl+B` | フォーカスをエディタに戻す |
| `Esc` | サイドバーを閉じる |
| `j` / `k` または ↑ / ↓ | 選択を移動 |
| `Enter` / `l` | ファイルを開く / フォルダを展開 |
| `h` | フォルダを折りたたむ |
| `<` / `>`（または `-` / `+`） | サイドバーをリサイズ |
