# タブ

複数のファイルを同時に開き、上部のクリック可能なタブストリップに表示します。各タブは
完全に独立しており、それぞれ独自のカーソル・選択・ビューポート・取り消し履歴を持ちます。

## キー

| キー | 動作 |
| --- | --- |
| `Ctrl+N` | 新しい空のタブを開く |
| `Ctrl+→` / `Ctrl+←` | 次 / 前のタブ（端で折り返し） |
| `Ctrl+W` | 現在のタブを閉じる |

## 挙動

- ファイルを開くと（[サイドバー](./sidebar)または[コマンドパレット](./command-palette)
  から）タブで開かれます。すでに開いていれば、そのタブにフォーカスします。空の未保存
  スクラッチバッファがある場合は、新しいタブを増やさずに再利用します。
- **未保存の変更があるタブを閉じる場合：** `Ctrl+W` はまず警告します — もう一度押すと
  破棄します。最後のタブを閉じると、新しい空のバッファが残ります。
- アクティブなタブにはアクセントマーカーが表示されます。`●` は未保存の変更を示します。

## マウス

- タブを**クリック**して切り替えます。
- **`✕` をクリック**して閉じます。未保存のタブはまず警告します — もう一度 `✕` を
  クリックすると破棄します。
- タブが収まりきらない場合、アクティブなタブが見えるようにストリップがスクロールします。
