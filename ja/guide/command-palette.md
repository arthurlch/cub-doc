# コマンドパレット

キーボードから離れずに、プロジェクト内の任意のファイルへ移動できるファジーファインダー
です。

## 使い方

**`Ctrl+P`** で開き、次のように操作します。

| キー | 動作 |
| --- | --- |
| 入力 | ファイルをファジーに絞り込み |
| ↑ / ↓ | 選択を移動 |
| `Enter` | 選択したファイルを開く |
| `Esc` | キャンセル |

ファイルを選ぶとタブで開きます（すでに開いていれば、そのタブにフォーカスします —
[タブ](./tabs) を参照）。

::: tip
`Ctrl+P` はファイル間を移動する最速の方法です。ディレクトリツリーを閲覧したい場合は、
代わりに[ファイルサイドバー](./sidebar)（`Ctrl+B`）を使いましょう。
:::
