# モーダル編集

Cub は Vim の伝統に沿ったモーダルエディタです。**ビューモード**は移動とテキスト操作、
**インサートモード**は入力のためのモードです。以下はすべてデフォルトで、グローバルと
ビューモードのキーはすべて[再割り当て可能](./configuration)です。

## ビューモード

| キー | 動作 |
| --- | --- |
| `i` / `a` | カーソルの前に挿入 / 後ろに追記 |
| `o` / `O` | 下 / 上に新しい行を開いて挿入 |
| `h` `j` `k` `l` または矢印 | 左 / 下 / 上 / 右へ移動 |
| `0` / `^` / `$` | 行頭 / 最初の非空白 / 行末 |
| `w` / `b` | 次 / 前の単語 |
| `gg` / `G` | ファイルの先頭 / 末尾 |
| `<数字>G` | 指定行へジャンプ（例：`42G`） |
| `PgUp` / `PgDn` | 半画面スクロール |
| `x` | カーソル位置の文字を削除 |
| `dd` / `yy` | 現在行を削除 / ヤンク（コピー） |
| `p` / `P` | 後ろに / 前に貼り付け |
| `u` / `Ctrl+R` | 取り消し / やり直し |

`dd` と `yy` は行単位でキャプチャしたことを覚えているため、`p` は下の新しい行に
（`P` は上に）貼り付けます — Vim と同じ挙動です。

## ビジュアル（選択）

`v` で選択を開始し、移動（`hjkl`、単語、行の移動）で範囲を広げます。

| キー | 動作 |
| --- | --- |
| `v` | ビジュアル選択の開始 / 解除 |
| `y` | 選択範囲をヤンク（コピー） |
| `d` / `x` | 選択範囲を削除（カット） |
| `p` | 選択範囲に貼り付け |
| `Esc` | 選択を解除 |

::: info
ビジュアルモードの操作子 `y`・`d`・`x`・`p` は固定です。常に選択範囲に作用し、再割り
当てはできません。
:::

## インサートモード

| キー | 動作 |
| --- | --- |
| `Esc` | ビューモードに戻る |
| 任意の文字 | 挿入する |
| `Enter` | 改行 |
| `Tab` | スペース 4 つを挿入 |
| `Backspace` / `Delete` | カーソルの前 / 位置を削除 |
| 矢印、`Home`/`End`、`PgUp`/`PgDn` | カーソル移動 |

## 取り消しの仕組み

取り消しとやり直しは**差分ベース**です。各変更は実際に変わった部分だけを記録するため、
大きなファイルでも小さなファイルでも 1 キーのコストは同じです。マルチカーソルの編集は
1 つの取り消しステップにまとまり、`u` 一回ですべて元に戻ります。

## グローバルキー（全モード共通）

| キー | 動作 |
| --- | --- |
| `Ctrl+S` | 保存 |
| `Ctrl+Q` | 終了 |
| `Ctrl+H` | ヘルプオーバーレイの表示切り替え |
| `Ctrl+P` | コマンドパレット（ファジーファインダー） |
| `Ctrl+T` | テーマ切り替え |
| `Ctrl+B` | ファイルサイドバー（表示 / フォーカス / 戻す） |
| `Ctrl+E` | サイドバーを反対側へ移動 |
| `Ctrl+←` / `Ctrl+→` | 前 / 次のタブ |
| `Ctrl+N` | 新しいタブ |
| `Ctrl+W` | タブを閉じる |
| `Ctrl+↑` / `Ctrl+↓` | 上 / 下にカーソルを追加 |
| `Ctrl+G` | 統合ターミナルの切り替え |
