# 統合ターミナル

Cub はエディタ下部のパネルに、組み込み VT エミュレータで動く本物のシェルを組み込みます
— 色、プロンプト、フルスクリーンプログラムも動作します。複数を同時に起動し、切り替え・
リサイズ・クローズを、エディタから離れずに行えます。

## 切り替えとフォーカス

`Ctrl+G` は状況に応じて動作します。

- **非表示** → パネルを表示してフォーカスします。
- **表示中でエディタにフォーカスがある** → ターミナルにフォーカスします。
- **フォーカス中** → パネルを非表示にします。

ターミナルにフォーカスがある間、キー入力はそのままシェルに送られます。**`Esc`** を押すと、
パネルを閉じずに**フォーカスをエディタへ戻します**。どちらのペインもクリックでフォーカス
できます。`Ctrl+Q` は常に Cub を終了します。

| キー | 動作 |
| --- | --- |
| `Ctrl+G` | ターミナルパネルの切り替え / フォーカス |
| `Esc` | フォーカスをエディタに戻す（パネルは開いたまま） |

## 複数のターミナル

ターミナルにフォーカスがある間：

| キー | 動作 |
| --- | --- |
| `Ctrl+N` | 別のシェルを開く |
| `Ctrl+W` | 現在のシェルを閉じる |
| `Ctrl+←` / `Ctrl+→` | シェルを切り替え |

パネルのヘッダーには `1 ✕  2 ✕  +` のような番号付きタブが表示されます。マウスでは次の
操作ができます。

- **番号をクリック**してそのシェルに切り替え、
- **`✕` をクリック**して閉じ、
- **`+` をクリック**して新しいシェルを開く。

## リサイズ

ターミナルにフォーカスがある間：

| キー / 操作 | 動作 |
| --- | --- |
| `Ctrl+↑` / `Ctrl+↓` | パネルを拡大 / 縮小 |
| ヘッダーバーをドラッグ | マウスでリサイズ |

各パネルはサイズを記憶し、ウィンドウに合わせてリサイズされます。終了時にはすべての
シェルが後始末されます。

::: warning シェルへ `Esc` を送る
`Esc` はフォーカスをエディタに戻すため、シェルには転送されません。ターミナル内で動く
フルスクリーンプログラムが `Esc` を必要とする場合、パネルが横取りするのはこのキーだけ
です — それ以外（`Ctrl+C`、`Ctrl+D`、矢印、タブ補完など）はすべてそのまま通過します。
:::
