# ファイルサイドバー

プロジェクトを移動するための、開閉・リサイズ可能なファイルエクスプローラです。

## キー

| キー | 動作 |
| --- | --- |
| `Ctrl+B` | サイドバーを表示してフォーカス。もう一度押すとサイドバーとエディタでフォーカスを切り替え |
| `Ctrl+E` | サイドバーを反対側にドッキング（左 ↔ 右） |
| `Esc` | サイドバーを閉じる（フォーカスをエディタに戻す） |
| `j` / `k` または ↑ / ↓ | 選択を移動 |
| `Enter` または `l` | 選択したファイルを開く、またはフォルダを展開 / 折りたたみ |
| `h` | 現在のフォルダを折りたたむ |
| `<` / `>`（または `-` / `+`） | サイドバーをリサイズ |

## フォーカス

フォーカスされているペインはハイライト（アクセントの枠線と選択色）され、もう一方は
暗く表示されるので、キー入力がどこに向かうか常に分かります。`Ctrl+B` はサイドバーを
閉じずにフォーカスを行き来させます。

エディタで現在開いているファイルは、ツリー内でハイライトされます。

## マウス

- エントリを**クリック**してファイルを開く、またはフォルダを切り替えます。
- **境界（`│`）をドラッグ**してサイドバーをリサイズします。テキストはその場で再配置
  されます。
- サイドバー上で**スクロール**してファイルツリーを移動します。
