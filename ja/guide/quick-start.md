# クイックスタート

ファイルを開きます（存在しない場合は保存時に作成されます）。

```bash
cub main.go
```

空のバッファで始めることもできます。

```bash
cub
```

## まず覚える 5 つのキー

これだけで作業を始められます。

| キー | 動作 |
| --- | --- |
| `i` | **インサートモード**に入る（入力開始） |
| `Esc` | **ビューモード**に戻る |
| `Ctrl+S` | 保存 |
| `Ctrl+Q` | 終了 |
| `Ctrl+H` | アプリ内のキーバインドヘルプを表示 |

## 30 秒ツアー

1. Cub は**ビューモード**で開きます。`h` `j` `k` `l`（または矢印キー）で移動します。
2. `i` を押して入力し、`Esc` でビューモードに戻ります。
3. 現在行を複製：`yy` のあと `p`。行を削除：`dd`。
4. テキストを選択：`v` を押し、移動して範囲を広げ、`y`（コピー）または `d`（削除）。
5. `Ctrl+S` で保存、`Ctrl+Q` で終了。

::: tip さらに試してみる
- **ファイルを素早く開く：** `Ctrl+P` でファジーファインダー、または `Ctrl+B` でサイドバー。
- **シェルを開く：** `Ctrl+G` で[統合ターミナル](./terminal)を切り替え。
- **見た目を変える：** `Ctrl+T` で[テーマ切り替え](./themes)。
- **マルチカーソル：** `Ctrl+↓`／`Ctrl+↑` でカーソルを重ね、一度入力すれば全行を編集。
:::
