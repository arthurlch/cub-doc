# Command palette

A fuzzy file finder for jumping to any file in your project without leaving the
keyboard.

## Usage

Press **`Ctrl+P`** to open it, then:

| Key | Action |
| --- | --- |
| type | Filter files fuzzily |
| ↑ / ↓ | Move the selection |
| `Enter` | Open the selected file |
| `Esc` | Cancel |

Selecting a file opens it in a tab (or focuses its existing tab if it's already
open — see [Tabs](./tabs)).

::: tip
`Ctrl+P` is the fastest way to hop between files. For browsing a directory tree
instead, use the [file sidebar](./sidebar) (`Ctrl+B`).
:::
