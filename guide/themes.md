# Themes & languages

Cub highlights **250+ languages** and ships **24 truecolor colorschemes** (dark
and light), all powered by [chroma](https://github.com/alecthomas/chroma).

A colorscheme drives per-token syntax colors *and* the derived UI colors (cursor
line, status bar, sidebar, borders), so everything stays cohesive whether you
pick a dark or a light theme.

## Switching themes

Press **`Ctrl+T`** to open the theme switcher:

| Key | Action |
| --- | --- |
| ↑ / ↓ | Preview the next / previous theme live |
| `Enter` | Apply the highlighted theme |
| `Esc` | Cancel and revert |

Your choice is saved automatically to the [config file](./configuration) and
restored next time you launch Cub.

- **tokyonight** — night, storm, day

## Languages

Syntax highlighting is per-token and covers 250+ languages — the language is
detected from the file extension, so it just works when you open a file.
